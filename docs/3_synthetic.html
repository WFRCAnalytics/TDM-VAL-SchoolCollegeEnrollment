Synthetic Population

PopulationSim synthetic enrollment estimates, by district and county

Overview

This script produces the “synthetic” half of the validation schema — PopulationSim’s estimate of how many K-12 students and college students live in each district/county, to compare against the real enrollment numbers from 2_enrollment.qmd.

  • Objective: for each district, count synthetic persons two ways — by enrollment status (PersonType_Label == "K-12 student", uncontrolled in PopulationSim, so this is the real test) and by age band (5-17, a controlled variable, so a sanity bound rather than an exact match). Same two-way count for colleges by county, using "University student" and a college-age band, combining PopulationSim’s regular household persons with its separate dorm/group-quarters student file.
  • What it reads: PopulationSim’s synthetic person/household output (local-only — gitignored in the TDM-INP-PopulationSim repo, so this script needs a local path to wherever that output actually lives on this machine, not a repo-relative path) and the block-level crosswalk from 1_geography.qmd.
  • MAZ/TAZ join: PopulationSim’s output is keyed at MAZ/TAZ level, not Census block. The crosswalk from 1_geography.qmd now carries TAZID per block (sourced from WFRC’s WasatchFrontTAZ feature service), so district/county rollup can go through TAZID rather than needing a direct MAZ-to-block join — still need to confirm PopulationSim’s output is keyed at this same TAZID (not a different internal MAZ id) before relying on it.
  • Box Elder: handled last — the MPO/TDM model region only partially covers the county, so its synthetic counts need to be clipped to the model boundary (1_geography.qmd’s model_boundary layer) rather than compared at full-county scope like the other four counties.
  • Output: synthetic enrollment-status and age-band counts, by district and by county, written to _outputs/.
