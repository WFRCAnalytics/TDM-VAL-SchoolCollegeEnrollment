# PopulationSim inputs and outputs

This folder holds local copies of PopulationSim inputs and outputs. Everything in it except this
README is gitignored, because the files are large, local-only, and regenerated by PopulationSim.

## What the pages read

| File (relative to this folder) | Read by | Notes |
|---|---|---|
| `ABM/1_Inputs/ScenarioBaseSample/1_PopulationSim/output/Persons_Output4ABMwithStudentsInDorm.csv` | `3_synthetic.qmd` | Final combined persons file, one row per synthetic person, including dorm students. Written by `5_PostProcessCombine.ipynb` in TDM-INP-PopulationSim (its `final_persons_file` setting). |

`3_synthetic.qmd` reads only three columns from that file: `maz_id`, `age`, and `sch_grade`. The
folder path is set once, in the `synthetic_dir` variable in `3_synthetic.qmd`.

## Other files here

- `ABM/.../output/Households_Output4ABMwithStudentsInDorm.csv` is the matching household file. No page
  reads it yet.
- The segment outputs that step 5 combines (`NonGQhouseholds/` and `StudentsInDorms/` under
  `1_PopulationSim/`) are inputs to that step. No page reads them.
- The shapefiles and the MAZ draft zip here are copies of PopulationSim inputs. The pages read the
  geometry under `_data/raw/geometry/`, not these copies.

## Refreshing

After a new PopulationSim run and step 5, copy the new `Persons_Output4ABMwithStudentsInDorm.csv`
to the `output/` path above, under the same name. Then re-render the site.
