# PopulationSim inputs

Files in this folder are PopulationSim inputs and outputs used by `3_synthetic.qmd`.

| File | Tracked in git | What it is |
|---|---|---|
| `maz_taz_equivalency.csv` | Yes | Lookup from PopulationSim `maz_id` to WFRC `TAZID`. Used to tie synthetic persons to TAZ-level geography. |
| `Persons_Output4ABMwithStudentsInDorm.csv` | No (local only) | PopulationSim synthetic persons, including students in dorms. One row per synthetic person. |
| `Households_Output4ABMwithStudentsInDorm.csv` | No (local only) | PopulationSim synthetic households. One row per synthetic household, keyed by `maz_id` and `hh_id`. |

The two output CSVs are large and regenerated by PopulationSim, so they are excluded in
`.gitignore`. To refresh them, copy the new files from the PopulationSim run output into this
folder under the same names.
